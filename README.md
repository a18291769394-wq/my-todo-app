# my-todo-app
A simple to-do list application with local storage functionality

## Java 运算符示例

新增两个独立程序：
- `src/TaskOneArithmetic.java`：任务一（变量与算术运算符）
- `src/TaskTwoAssignmentComparison.java`：任务二（赋值与比较运算符）

### 运行方式

```bash
javac src/TaskOneArithmetic.java src/TaskTwoAssignmentComparison.java
java -cp src TaskOneArithmetic
java -cp src TaskTwoAssignmentComparison
```
